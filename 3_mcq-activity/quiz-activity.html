Module Item Completion (built in browser, hidden in app)

Learning outcome addressed

  1. Choose a responsible response when AI-generated learning content contains an unsupported claim.

Quiz Activity

Read the scenario and select one correct answer. Select Check answer to view feedback. Select Try again to clear your answer and start again.

An AI tool drafts a workplace learning guide. It includes a confident claim that you cannot find in the source document. What should you do before sharing the guide?

The average completion time for this activity is 3 minutes.

This is a self-study activity and does not count towards programme completion.
